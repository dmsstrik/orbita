# Орбита

Локальное приложение для исследования симметрий социальных графов и поиска структурно похожих аккаунтов. Реализует согласованный план практической части диплома: импорт, точные орбиты, объяснение кандидатов, визуализация, модельные эксперименты и отчёты.

## Запуск через Docker

Требуется установленный Docker. Из папки проекта:

```bash
docker compose up --build
```

Приложение откроется по адресу **http://127.0.0.1:8787**. Останов: Ctrl+C либо `docker compose down`.

Сбор VK использует токен из файла `.env` рядом с compose.yaml (строка `VK_TOKEN=...`). Без этого файла приложение работает полностью — кроме сбора VK. Сохранённые проекты хранятся в docker-томе `orbita-projects`.

## Запуск без Docker (macOS, локальный Python)

Откройте **«Запустить Орбиту.command»** двойным щелчком. Приложение откроется по адресу **http://127.0.0.1:8787**. Окно терминала должно оставаться открытым; Ctrl+C останавливает сервер.

Альтернатива из папки проекта:

```bash
./run.sh
```

Зависимости уже установлены в `.venv`. После установки импорт файлов, расчёты, проекты и отчёты работают без интернета. Сеть нужна только для первоначальной установки пакетов и выбранного пользователем сбора VK.

Если порт занят: `./run.sh --port 8788`. Для работы без автоматического открытия браузера: `./run.sh --no-browser`. Токен VK берётся из переменной окружения `VK_TOKEN` или из файла `.env` в папке проекта.

## Первое исследование

1. При открытии автоматически анализируется **синтетический демонстрационный граф**. Это учебные данные, а не выявленные реальные боты.
2. В разделе **«Данные»** загрузите CSV/JSON или выберите другой пример. При необходимости добавьте файл меток `id,truth` или `id,clone_of`.
3. Выберите корень, радиус окрестности, порог оценки и учёт корня при сравнении соседей. Нажмите **«Анализировать»**.
4. В разделе **«Граф»** исследуйте орбиты и связи; в **«Кандидатах»** выберите пару, чтобы увидеть основания её выделения.
5. Сохраните проект локально или выгрузите JSON-граф, CSV кандидатов и самостоятельный HTML-отчёт.
6. В **«Опытах»** задайте число клонов, долю сохраняемых связей, уровни шума, число повторов и seed. Сравните три метода на одних и тех же изменённых графах.

В папке `examples/` есть готовые файлы: `social.json`, `social.csv`, `labels.csv`, `star.json`, `asymmetric.json`. CSV со списком рёбер не хранит изолированные вершины, поэтому JSON — основной формат для полного сохранения графа. Подробности в [examples/README.md](examples/README.md).

## Что реализовано

- CSV, TSV, списки рёбер и JSON; нормализация, проверка ссылок, дублей, петель, разметки и ограничений.
- Неориентированные графы до **2000 вершин / 100 000 рёбер**. Превышение лимитов отклоняется, граф не обрезается молча.
- Точные автоморфизмы и орбиты через **nauty / pynauty**, в том числе фиксация центральной вершины. Группа представляется без полного перебора всех её элементов.
- Метрики графа, размер орбит, обычный коэффициент Жаккара открытых окрестностей, отдельные пояснения для смежных и несмежных структурных двойников.
- Интерактивный SVG-граф с масштабированием, перемещением и выбором вершин/пар; таблица кандидатов и объяснения.
- Независимая оценка по предоставленным полным bot/human-меткам; неполные метки не превращаются в отрицательные.
- Воспроизводимые модельные эксперименты: полное/частичное копирование связей, шум, контроль без внедрения, три метода и precision/recall/F1/FP/время.
- Локальные проекты; выгрузки JSON, CSV и HTML без внешних ресурсов.
- Дополнительный адаптер **VK API**, который сохраняет сведения о неполноте и выборке.
- Пакетный запуск без интерфейса через CLI.

## Математическая модель

Для пары вершин вычисляются `J` — коэффициент Жаккара и `O` — индикатор общей точной орбиты при непустых сравниваемых окрестностях. Структурная оценка:

```text
S = (O + J) / 2
```

Пара попадает в кандидаты при `S ≥ порог` и наличии ненулевого структурного признака. Это **не вероятность бота**. При пороге выше `0.5`, включая начальные `0.65`, комбинированное правило требует общей точной орбиты. Поэтому разрушение симметрии может снизить полноту относительно простого сходства соседей. Исследовать этот эффект — часть назначения программы.

Корень фиксируется в группе автоморфизмов и исключается из пар. По умолчанию он также исключён из сравниваемых соседств: одна общая связь с центральным пользователем недостаточна. На звезде при таком режиме кандидатов не будет, хотя листья лежат в одной орбите.

Орбиты вычисляются точно. Очень большой порядок группы nauty возвращает как число с плавающей точкой и степень десяти; такой порядок явно помечается как приближённый. Если раскладке большого графа не хватает дополнительного компонента SciPy, используется круговое расположение: это меняет только картинку.

Подробные определения, протокол экспериментов и ограничения: [docs/METHODOLOGY.md](docs/METHODOLOGY.md).

## Формат данных

Минимальный CSV:

```csv
source,target
alice,bob
alice,carol
bob,carol
```

JSON с изолированной вершиной и метаданными:

```json
{
  "name": "Мой граф",
  "nodes": [
    {"id": "alice", "label": "Аккаунт A"},
    {"id": "bob", "label": "Аккаунт B"},
    {"id": "isolated", "label": "Изолят"}
  ],
  "edges": [{"source": "alice", "target": "bob"}],
  "metadata": {"source": "manual", "root": "alice", "warnings": []}
}
```

Дополнительные поля вершины: `truth` со значением `bot`, `human` или `unknown`; `clone_of` — ID исходной вершины. Метки никогда не участвуют в вычислении орбит или оценки сходства. Неизвестных аккаунтов нельзя автоматически размечать людьми. Для файлов рекомендуется UTF-8.

## VK

В разделе данных укажите **числовой ID** центрального пользователя, токен с подходящим доступом к API и размер выборки от 1 до 80 друзей. Сбор выполняется только после нажатия кнопки. Токен не сохраняется в проекте или графе, не помещается в URL и не включается в сообщения ошибок.

Адаптер получает списки друзей через официальный `friends.get`, учитывает пагинацию, ограничивает частоту и время запросов. Закрытые профили, неполные списки и ограниченная выборка отражаются в метаданных. Полученный граф является снимком наблюдаемых связей. CAPTCHA и ошибки разрешений не обходятся.

Адаптер проверен на моделируемых ответах API. **Сбор с настоящим токеном VK не проверялся**: в проекте нет учётных данных. Доступность реального графа зависит от текущих разрешений VK и профилей.

## Пакетные исследования

Из папки проекта:

```bash
.venv/bin/python -m app.cli analyze examples/social.json --root ego --out output/demo
.venv/bin/python -m app.cli experiment examples/social.json --root ego --retention 0.8 --noise 0 0.05 0.15 --repeats 3 --seed 42 --out output/experiment
```

`analyze` сохраняет исходный граф, выбранный подграф (`subgraph.json`), результат анализа, кандидатов CSV и HTML-отчёт. `experiment` сохраняет исходный граф, все результаты JSON/CSV и пример изменённого графа. Параметры записываются в результат, поэтому опыт можно воспроизвести. Времена выполнения будут отличаться между запусками.

CLI экспериментов использует весь переданный граф и фиксирует указанный корень, без автоматической обрезки по радиусу. Для опыта на конкретной окрестности сначала сохраните её кнопкой «JSON подграфа» на странице графа или используйте `subgraph.json` из результата CLI-анализа.

## Установка на другом компьютере

Python 3.11 или новее; рекомендуется Python 3.12. При сборке pynauty из исходников может потребоваться C-компилятор (на macOS — Command Line Tools).

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

`requirements.lock` фиксирует версии всех пакетов, использованных при проверке этой сборки. Для воспроизведения того же окружения можно установить `-r requirements.lock`. При сетевых ограничениях используйте доступное доверенное зеркало Python; в приложении адрес зеркала не зашит.

Сервер привязан только к `127.0.0.1`. Для публичного размещения потребуются отдельные настройки авторизации, хранения и инфраструктуры; эта версия предназначена для локальной работы.

## Проверка и устройство проекта

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest
```

Полная проверка этой сборки: **142 автоматических теста**. Дополнительно проверены реальные сценарии в браузере: импорт, разметка, анализ, интерактивный граф, кандидаты, эксперименты, экспорты и сохранение/открытие/удаление проекта. Повторить браузерный сценарий можно при установленном Playwright командой `node tests/browser-smoke.cjs`; приложение перед этим должно быть запущено.

- `app/ingest.py`, `app/vk.py` — входные данные и происхождение наблюдений.
- `app/analysis.py` — точный анализ графов и оценка кандидатов.
- `app/experiments.py` — генерация, шум и сравнительная оценка.
- `app/main.py`, `app/jobs.py` — API и отдельные вычислительные процессы с ограничением времени.
- `app/storage.py`, `app/exports.py` — локальные проекты и отчёты.
- `static/` — интерфейс без сборщика и внешних CDN.
- `tests/` — математические, импортные и интеграционные проверки.
- `data/projects/` — проекты, сохранённые пользователем; в распространяемый архив не включаются.

При экспериментальной оценке измеряется восстановление известных синтетических добавлений. Чтобы делать выводы о настоящих ботах или клонах личности, нужна подходящая независимая разметка реальных данных.
